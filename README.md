# Solutions to *Algebra: Chapter 0* by Paolo Aluffi

**Author:** Vladyslav Chornyi  

## Overview
This repository contains my personal, rigorously typeset solutions to the exercises in *Algebra: Chapter 0* by Paolo Aluffi. I am working through this text as part of my independent study.

This is an ongoing project. The repository is actively being updated with new solutions as I progress through the chapters. 


## Methodology
All mathematical proofs and logic are my own original work. To streamline the digitization process, I draft my solutions by hand and utilize Google Gemini Pro to assist with LaTeX transcription, formatting, and minor proofreading.
